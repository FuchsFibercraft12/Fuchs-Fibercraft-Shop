# 🔥 FuchsFibercraft Shop Website

Eine moderne, responsive Shop-Website mit krassen Neon-Effekten, Animationen und interaktiven Elementen.

## ✨ Features

- 🎨 **Neon Glow Effects** - Leuchtende Neon-Farben überall
- ✨ **Glitch Animation** - Coole Glitch-Effekte im Header
- 💫 **Particle Background** - Animierte Partikel im Hintergrund
- 🌈 **Smooth Animations** - Fließende Übergänge und Hover-Effekte
- 💰 **Blinkender PayPal Link** - Auffälliger Link zum Spenden
- 💜 **Discord Integration** - Discord Server Link
- 📱 **Responsive Design** - Funktioniert auf allen Geräten
- ⚡ **Fast & Lightweight** - Keine schweren Dependencies

## 🚀 Wie du die Website nutzt

### 1. Links aktualisieren
Öffne `index.html` und ersetze:
- `https://discord.gg/DEIN-DISCORD-LINK` mit deinem Discord Server Link
- `https://paypal.me/DEIN-PAYPAL-USERNAME` mit deinem PayPal Link

### 2. Lokal testen
Öffne einfach die `index.html` Datei in deinem Browser. Keine Installation nötig!

### 3. Online hosten (GitHub Pages aktiviert)
Deine Website ist bereits unter folgendem Link erreichbar:
- https://FuchsFibercraft12.github.io/Fuchs-Fibercraft-Shop/

## 🛠️ Anpassungen

### Produkte hinzufügen/ändern
Bearbeite die `products-grid` Section in `index.html`:

```html
<div class="product-card">
    <div class="product-image">🎮</div>
    <h3>Dein Produktname</h3>
    <p class="price">€99,99</p>
    <p>Deine Beschreibung</p>
    <button class="buy-btn">In den Warenkorb</button>
</div>
```

### Farben ändern
Ändere die CSS Variables in `style.css`:

```css
:root {
    --neon-pink: #ff006e;      /* Deine Farbe */
    --neon-cyan: #00d9ff;      /* Deine Farbe */
    --neon-purple: #b000d9;    /* Deine Farbe */
    --neon-green: #39ff14;     /* Deine Farbe */
}
```
